Buka Firebase Console

Agar data undangan dan buku tamu dapat dibaca dan ditulis oleh tamu di HP/laptop mana saja, pastikan aturan di tab Rules Firestore sudah diatur ke allow read, write: if true;: 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
